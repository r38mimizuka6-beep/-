# 検索データに何が必要か

商圏レポート（調査会社のExcel）で埋まらない項目を、店舗名での検索・地図・
店頭観察で補うのが「検索データ」です。**項目は多ければよいものではありません。**
5店舗しかないので、変数を増やすほど偶然の一致が増えるだけです。

---

## 結論：軸3（移動手段）だけが検索データに依存しています

類似店の選定は3軸でおこないます。それぞれ何から計算しているかを調べました。

| 軸 | 使う変数 | 検索が必要 |
|---|---|---|
| 軸1 昼夜人口比 | 昼夜間人口比 / 従業者数比 / 生徒学生数比 / 事業所密度 | **1 / 4** |
| 軸2 世帯構成 | 単身・子育て・高齢世帯比率 / 平均世帯人員 / 65歳以上比率 | **0 / 5** |
| 軸3 移動手段 | 徒歩自転車比率 / 鉄道比率 / 車比率 / 駐車台数密度 / 駅距離 | **5 / 5** |

軸2は商圏レポートだけで完結します。軸1も4分の3は揃います。
**軸3は1つも揃いません。** ここが空のままだと、類似店が3軸ではなく2軸で選ばれ、
似ている店の顔ぶれが変わります（実際にダミーデータで検証したところ、
「都心A店・旧市街D店」が「都心A店・住宅街C店」に入れ替わりました）。

---

## 優先度A：これだけは全店そろえる（7項目）

| 項目 | 集め方 |
|---|---|
| **来店手段 徒歩 / 自転車 / 車 / 鉄道** | **検索では出ません。** 店頭観察か自社調査 |
| **売場面積(m2)** | 自社マスタが最優先。無ければ大規模小売店舗立地法の届出（都道府県サイトで公開） |
| **駐車場台数** | 公式サイトの店舗情報。記載が無ければ航空写真で数える |
| **最寄駅までの距離(m)** | 地図の徒歩ルート。徒歩分数しか無ければ 1分＝80m で換算（本ツールが自動でやります） |

加えて、軸ではありませんが **オープン日** が必須です。
開店直後の数週間は需要が跳ねるため、この日付が無いと各店の水準が歪みます。
業態転換ならその転換日を入れてください。

### 来店手段をどう埋めるか

これは検索しても出てこないので、方法は3つです。

1. **店頭観察** — 入口で15分×3回（平日朝・平日夕・土日昼）数える。全店同じ時間帯・同じ回数で
2. **レジでの聞き取り** — サンプル数は少なくてよいので、全店同じ設問で
3. **全店とも空欄にする** — 軸3が落ちて2軸での判定になり、レポートにその旨が出ます

**いちばんやってはいけないのは、一部の店だけ埋めることです。** 観察で埋めた店と
推定で埋めた店が混ざると、似ているかどうかの判定が手法ではなく記入方法を
反映してしまいます。3番目（全店空欄）のほうがまだ健全です。

## 優先度B：軸には入らないが、苦戦カテゴリーの説明に効く

予測値そのものは変わりませんが、「なぜこのカテゴリーが苦戦しそうか」を
言葉にするときに使います。

| 項目 | なぜ要るか |
|---|---|
| 最寄競合の店名・距離(m)・価格帯(1-5) | 低温は価格競争になりやすい。「最寄競合がディスカウントで320m」は打ち手につながる |
| 競合SM数(1km内) | 同上 |
| 競合ドラッグ数(1km内) | 牛乳・ヨーグルト・冷凍を安く置くので、低温の実質的な競合 |
| 競合CVS数(1km内) | 軸1の事業所密度の計算に使います |
| 最寄駅1日乗降客数 | 通行量の代理。駅前店の説明に使う |

---

## 優先度C：5店舗では増やさないほうがよい

大学数・工場数・病院数・集合住宅戸数など。関係がありそうに見えますが、
**5店舗に対して変数を8個足すと、偶然そろう項目が必ず出ます。**
本ツールは「偶然なら何件一致するはず」を計算して表示しますが、
そもそも足さないのがいちばん確実です。

後から足すことはいつでもできます。実績データが溜まり、予実検証で
「この項目があれば説明できたのに」とわかってから足してください。

---

## いちばん大事な注意：全店で基準をそろえる

件数を数える項目は、**半径・数え方が店ごとに違うと比較が壊れます。**

- 半径1kmなら全店1km。駅周辺ではなく**店舗を中心**に
- 「スーパー」に何を含めるか（生協は？業務スーパーは？）を決めて全店同じに
- 調べた日付を `searched_at` に残す。1年経ったら揃えて取り直す

いただいたサンプルブックには「駅周辺の半径1km以内」と備考がありました。
本ツールはこの備考を読み取って画面に表示します。**店舗ごとに違っていないか、
登録前に必ず確認してください。**

## 検索クエリの例

店舗名を `○○店` として、そのまま貼れる形です。

```
○○店 住所 営業時間
○○店 駐車場 台数
○○店 売場面積
○○店 大規模小売店舗立地法 届出
○○店 最寄駅 徒歩
（最寄駅名） 乗降人員 2023年度
```

地図サービスでは、**店舗を中心に**して半径を固定し、次を検索して数えます。

```
スーパー / ドラッグストア / コンビニ / 業務スーパー
小学校 / 中学校 / 保育園 / 幼稚園
```

## ブックに足してほしい行

いただいた `商圏サマリー` シートに、以下の行を足すだけで
優先度Aが全部そろいます。項目名はこのとおりでなくても、
近い表記なら読み取ります。

| 項目 | 詳細情報の例 | 備考の例 |
|---|---|---|
| 売場面積 | 1,480 m2 | 自社マスタ |
| オープン日 | 2024年3月15日 | 業態転換日 |
| 来店手段 徒歩 | 42% | 店頭観察 15分×3回 |
| 来店手段 自転車 | 38% | 同上 |
| 来店手段 車 | 8% | 同上 |
| 来店手段 鉄道 | 12% | 同上 |
| 最寄競合の店名 | ○○マート駅前店 | |
| 最寄競合までの距離 | 320m | |
| 最寄競合の価格帯 | 3 | 1低-5高 |

`42%` でも `0.42` でも読みます。`144台` `約52,593人 / 日` `1,480 m2` の
ような書き方のまま入れて構いません。数値だけ取り出します。

## 読み取れる項目・読み取れない項目

アップロードすると、何をどう解釈したかが画面に出ます。

- `駅乗降客数「約52,593人 / 日」→ 52593` のように、変換の内容を表示します
- `徒歩約4〜5分 → 360m（目安です）` のように、推定したものは明示します
- 分類できなかった施設区分（例：大型公園・レジャー）は**数に入れず**、名前を挙げます
- 読み取れなかった項目は**空のまま**です。推測で埋めません

登録前に表で直せます。おかしな値があれば、その場で上書きしてください。
