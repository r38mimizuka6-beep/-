■ 起動できないときの対処（Windows）

----------------------------------------------------------------
1. start.bat をダブルクリックすると黒い画面が一瞬で消える
   / 文字化けしたエラーがたくさん出る
----------------------------------------------------------------
古いバージョンの start.bat を使っています。
GitHub から ZIP をダウンロードし直してください。
（2026-10-06 以降のものは修正済みです）

ダウンロードし直すときは、いまお使いの shoken_analyzer フォルダの
  data フォルダ      ← 蓄積したデータ
  output フォルダ    ← 出力したレポート
を先にデスクトップなどへ退避し、新しいフォルダに上書きで戻してください。

----------------------------------------------------------------
2. [ERROR] Python was not found on this PC.
----------------------------------------------------------------
Python が入っていません。

  1) https://www.python.org/downloads/windows/ を開く
  2) Python 3.11 以降をダウンロードしてインストール
  3) ★インストーラ最初の画面で
     「Add python.exe to PATH」に必ずチェックを入れる★
  4) PC を再起動してから start.bat をもう一度ダブルクリック

----------------------------------------------------------------
3. [ERROR] Could not install the libraries.
----------------------------------------------------------------
社内ネットワークの制限で、ライブラリの配布元に接続できていません。
情報システム部門に、以下への接続許可を依頼してください。

  https://pypi.org
  https://files.pythonhosted.org

----------------------------------------------------------------
4. [ERROR] Could not create the .venv folder.
----------------------------------------------------------------
フォルダを OneDrive や共有ドライブの下に置いていると失敗することが
あります。shoken_analyzer フォルダごと C:\ の直下などに移動してから、
中にある .venv フォルダ（あれば）を削除して、もう一度お試しください。

----------------------------------------------------------------
5. [ERROR] app\dashboard.py was not found next to this file.
----------------------------------------------------------------
start.bat だけを別の場所にコピーしています。
start.bat は shoken_analyzer フォルダの中に入れたまま使ってください。

----------------------------------------------------------------
6. 手動で起動したい（上記で直らないとき）
----------------------------------------------------------------
shoken_analyzer フォルダをエクスプローラで開き、
アドレスバーに「cmd」と入力して Enter。
黒い画面が開いたら、以下を1行ずつ貼り付けて実行してください。

  py -3 -m venv .venv
  .venv\Scripts\python.exe -m pip install -r requirements.txt
  .venv\Scripts\python.exe -m streamlit run app/dashboard.py

エラーの文面をそのままコピーして相談いただければ、原因を特定できます。

----------------------------------------------------------------
7. 毎回 start.bat を開くのが面倒
----------------------------------------------------------------
start.bat は初回セットアップ用です。日常では使いません。

  setup_autostart.vbs を1回ダブルクリック
    → ログイン時に裏で自動起動し、デスクトップにアイコンができます

普段は、デスクトップの「低温予測ダッシュボード」をクリックするか、
ブラウザで http://localhost:8501 を開くだけです。

止めたいときは stop_dashboard.vbs。
起動の記録は logs\dashboard.log に残ります。

----------------------------------------------------------------
8. ログに「Port 8501 is not available」と出る
----------------------------------------------------------------
前回のサーバーが残っています。stop_dashboard.vbs で止めてから、
open_dashboard.vbs で開き直してください。

----------------------------------------------------------------
※ 本ツールは全て手元のPCの中だけで動きます。
   実データが社外に送信されることはありません。
----------------------------------------------------------------
