## まだ空欄の項目（埋め方）

| 列名 | 埋め方 |
|---|---|
| `parking_spaces` | 公式サイトの店舗情報。無ければ航空写真で概算 |
| `sales_floor_sqm` | 自社マスタ優先。無ければ大規模小売店舗立地法の届出 |
| `share_walk` / `share_bike` / `share_car` / `share_train` | 既存店は店頭観察か自社調査。新店は駐車場規模と立地から想定 |
| `comp_sm_1km` / `comp_sm_3km` / `comp_cvs_1km` / `comp_drug_1km` / `comp_discount_1km` | 地図で店舗を中心に検索し件数を数える。**半径を全店で必ず揃える** |
| `nearest_comp_m` / `nearest_comp_price` | 最も近いSMまでの道なり距離と価格帯（1=ディスカウント 5=高品質） |
| `fac_school` / `fac_nursery` / `fac_university` / `fac_factory` / `fac_apartment_units` | 地図で半径1km内を数える |
| `pop_density` | 商圏人口 ÷ 商圏面積（商圏レポートに面積があればそこから） |
| `own_store_overlap` | 自社店舗網との商圏の重なり。自社マスタから |

## 注意

- 件数系（競合・施設）は**必ず同じ半径**で数えてください。店によって半径が違うと、
  類似度の距離計算が壊れます。
- `nearest_comp_price` は主観が入る項目です。全店を同じ人がつけるか、
  売価調査の実数に置き換えてください。
- 町田は**館の構成が変わる**（TSUTAYA退店）ため、競合だけでなく
  館内の集客源の変化も商圏変数として記録しておくと、後の答え合わせで効きます。
